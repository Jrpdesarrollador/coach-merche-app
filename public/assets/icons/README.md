# Iconografía de la app

Generados por reescalado de alta calidad desde `../brand/logo-coach-merche.png` (1024x1024):

- `pwa-icon-192-green.png` (192x192)
- `pwa-icon-512-green.png` (512x512)
- `pwa-apple-touch-green.png` (180x180)
- `pwa-icon-maskable-512-green.png` (512x512, `purpose: "maskable"`) — el emblema ocupa exactamente
  el 80% del lienzo (zona segura de Android) sobre `#0a0a0a`.

Regenerar: `npm run icons:build`
